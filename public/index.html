Características Principales

Sistema completo de gestión TR069 con todas las funcionalidades necesarias

Gestión de Dispositivos

Cambio remoto de SSID y contraseñas WiFi, configuración de DNS, VLAN, PPPoE y parámetros de red.

Monitoreo y Diagnóstico

Visualización de potencia óptica (dBm), estado de conexión, nivel de señal y dispositivos conectados al WiFi.

Automatización Masiva

Perfiles automáticos que configuran las ONT al conectarse y asignación automática a clientes.

Operaciones Remotas

Reinicio remoto de equipos, actualizaciones de firmware y reset de fábrica desde el panel web.

Portal de Cliente

Panel web donde los clientes pueden cambiar su WiFi sin necesidad de soporte técnico.

Integración Completa

Detección automática de ONT, base de datos MySQL y API REST completa para integraciones.

Especificaciones Técnicas

Protocolo TR069/CWMP completo
Compatible con ONT Huawei
Base de datos MySQL
API REST completa
Interfaz web responsive
Logs y monitoreo detallado

Inicio Rápido

Configuración del Servidor
# 1. Instalar dependencias
npm install

# 2. Configurar variables de entorno
cp .env.example .env
# Editar .env con tu configuración

# 3. Crear base de datos
npm run migrate

# 4. Iniciar servidor
npm start

Endpoints principales:

  • POST /acs - Endpoint TR069 CWMP
  • GET /admin - Panel de administración
  • GET /client - Portal de cliente
  • GET /api/docs - Documentación API
